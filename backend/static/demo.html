Chat widget preview

Backend is live. This page simulates your website — the widget is added with one script tag.

Try this now

  1. Click the yellow button in the bottom-right corner.
  2. Click a quick-reply chip, e.g. "Python course fee?".
  3. Type who teaches java and press Enter.
  4. Ask a follow-up: and python? — it should keep context.
  5. Type how much is the data analytics course.
  6. Type do you teach cyber security — it must refuse, not invent.
  7. Watch the 0 / 500 counter while typing.
  8. Use the – (minimize) and × (close) icons, then reopen.
  9. Refresh the page — chat history resets (it lives in the tab only).

The widget is isolated in Shadow DOM, so your site's CSS cannot break it.

Integration (later)

  • One script tag, no build step, works on WordPress, Shopify, plain HTML or React.
  • Options: data-theme, data-accent, data-title, data-api.
  • Requires the backend to be deployed with HTTPS and your domain in CORS.
